# Stlačování látek

Interaktivní simulace lisu s pevnou látkou a kapalinou. Uživatel táhne píst dolů a pokouší se látku stlačit. Mezi situacemi se přepíná tlačítky **pevná** / **kapalná**.

Scény vycházejí z Lottie animací (válec, píst, látka, detail částic).

## Spuštění lokálně

```bash
npm start
```

Aplikace poběží na adrese **http://localhost:3480**.

## Ovládání

- **Přepínač pevná / kapalná** — zvolí scénu
- **Táhni píst dolů / nahoru** — zkus stlačit látku a píst zase zvedni
- V kruhu vpravo nahoře se pořád pohybují částice
